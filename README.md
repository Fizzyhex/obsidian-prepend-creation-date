# Prepend Creation Date

This is a simple Obsidian plugin that makes it easy to date notes in your Obsidian Vault.

Run it from the file explorer or command palette!

![Multi Prepend Example](media/multi-prepend-example.gif)

## Features

- Batch Editing
- Command Palette & Files Support

## Installation

### From Obsidian

Open **Settings** → **Community plugins**, search for **Prepend Creation Date**, then install and enable it.

### Manual installation

1. Download `main.js` and `manifest.json` from the [latest GitHub release](../../releases/latest).
2. Create a folder named `prepend-creation-date` in your vault at `.obsidian/plugins/`.
3. Copy both downloaded files into that folder.
4. In Obsidian, open **Settings** → **Community plugins**, press the **reload button**, and enable **Prepend Creation Date**.

For updates, replace the two files with the versions from a newer release, then press 🔄️ in the Community Plugins menu.
